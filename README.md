# ローカルじゃんけんゲーム エディター v1

GitHub Pages上のPWAから、スマホ/PCで選択したローカルゲームフォルダの
`game.json` と画像を読み込み、ゲーム内容を編集できます。

## フォルダ構成

sample_game/
- game.json
- images/
  - rock.svg
  - paper.svg
  - scissors.svg

## できること

- ゲームタイトル変更
- 説明変更
- バージョン変更
- グー/パー/チョキの表示名変更
- 勝てる相手の変更
- 画像パス変更
- 手ごとの画像ファイル差し替え
- 編集した `game.json` を選択したローカルフォルダへ保存
- 編集後の内容ですぐじゃんけんをプレイ

## 注意

最初の「ゲームフォルダを選択」で、書き込み許可を求められた場合は許可してください。
画像を差し替える場合、元の画像と同じフォルダに新しい画像ファイルが保存されます。


## v2 画像素材管理
- 選択したゲームフォルダ内の画像を再帰的に一覧表示
- `images/` へ画像を追加
- 画像を削除
- 既存画像を各手へ割り当て
- 使用中の画像を削除する際は確認
- 画像変更後に `game.jsonを保存` で設定を保存
